Duplicate and stop rules

  • One open Founding Students opportunity per contact and current On-Demand Revenue Engine sales motion.
  • Search by email first. Use external lead ID as the secondary identity. Never use name alone.
  • Every event stores its external event ID. If no event ID exists, use source plus contact ID plus event type plus source timestamp.
  • No-show identity is Appointment ID plus No-show status plus source timestamp.
  • Rebooking ends the active recovery, but a later separate no-show can start one new recovery.
  • Purchase, opt-out, cancellation, disqualification, and trial end stop or branch the relevant follow-up.
  • Replies pause automated follow-up and create a human task.
