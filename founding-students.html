S1

S1 - FOUNDING STUDENTS - Call Booked

What starts it: Runs when the OFFICIAL Blueprint Call is booked or rebooked.

What each part does

  1. Reject known older bookings before changing sales state: if this ID is already in appointment history but is not the active ID, stop with no changes.
  2. Current appointment already remembered: jump to the original Stop E2 action without appending history again.
  3. New appointment: append the prior active ID and incoming ID to slm_sales_appt_seen_ids, then join the original chain.
  4. Stop the E2 no-show recovery workflow.
  5. Remove the no-show and canceled tags.
  6. Create or update the same Founding Students opportunity at Call Booked. Duplicate creation and backward moves are disabled.
  7. Write booked and this appointment ID to the two shared trial fields.

Proof: Published version 8. PASS: actual booking and replacement booking updated the same sales record. S1 v8 remembers appointment IDs and rejects known older confirmations. E1 v70 blocks the same old event; its allowed path delivered the first email after the normal wait. Public initial booking and SMS remain untested.

S2

S2 - FOUNDING STUDENTS - No Show Recovery

What starts it: Runs when the OFFICIAL Blueprint Call is marked No-show.

What each part does

  1. Compare this event's appointment ID with the contact's saved active ID. A mismatch or missing ID ends here without changes.
  2. Add the no-show tag. This starts E2 recovery once for an eligible contact.
  3. Move the same Founding Students opportunity to In Chase.
  4. Write no_show and the matching appointment ID to the two shared trial fields.

Proof: Published version 6. PASS: S2 v6 accepts a matching No show event, starts E2 once and moves the same record to In Chase. A controlled mismatching event stops before tags, pipeline or field changes. False cancellation email routing was fixed. SMS remains untested.

S3 - FOUNDING STUDENTS - Call Held

What starts it: Runs when the OFFICIAL Blueprint Call is marked Showed.

What each part does

  1. Compare this event's appointment ID with the saved active ID. A mismatch or missing ID ends here without changes.
  2. Move the same Founding Students opportunity to Call Held.
  3. Write completed and the matching appointment ID to the two shared trial fields.
  4. Remove the no-show tag, so this person is no longer labeled as having missed the call.
  5. Remove the contact from E2 no-show recovery, including an active waiting sequence.

Proof: Published version 7. PASS: S3 v7 accepts the current Showed event, moves the same sales record to Call Held, writes completed and matching ID, clears the no-show tag and stops active E2. A controlled mismatching event was rejected before these effects. Alex review remains open.

S5

S5 - FOUNDING STUDENTS - Blueprint Call Canceled

What starts it: Runs when the OFFICIAL Blueprint Call is canceled.

What each part does

  1. Compare this event's appointment ID with the saved active ID. A mismatch or missing ID ends before any cancellation effects.
  2. Write canceled and the current appointment ID to the two shared trial fields.
  3. Remove the no-show tag.
  4. Stop E2 no-show recovery.
  5. Send the cancellation email only after an actual cancellation. Calendar contact notices no longer send this email for no-shows.
  6. Leave the pipeline stage unchanged until Alex decides the cancellation-stage rule.

Proof: Published version 5. PASS: S5 v5 accepts matching cancellation, writes canceled and stops E2; the cancellation email action runs. A controlled mismatching event ends without changing the newer booking fixture. Earlier v4 cancellation Gmail receipt passed. Alex review remains open.
